# Security policy

Report security issues privately through GitHub's **Report a vulnerability** feature for this repository. Do not publish exploit details, private notes, tokens, cookies, or Edge profile data in a public issue.

The plugin is desktop-only and can read or write the vault and website paths selected in settings. Review paths and file lists in the sync and push previews before confirming. Keep Obsidian, Git, and the Wechatsync browser extension up to date.
